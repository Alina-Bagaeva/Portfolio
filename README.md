# 1. SQL

Коллекция SQL-запросов для аналитики данных: финансовые отчёты, движeние денежных средств, анализ клиентского поведения и активность сотрудников.

## Состав

| Файл | Назначение |
|------|-----------|
| `OFR2_hierarcy.sql` | Отчёт о финансовых результатах (ОФР) с иерархией строк и сравнением с прошлым годом |
| `ostatki_dds_short.sql` | Витрина движения и остатков денежных средств по дням, организациям и статьям ДДС |
| `Retail_depth_only_initial_purchases.sql` | Анализ первой не-розничной продажи клиентов относительно первой розничной лицензии |
| `bills_payments_messages_chats.sql` | Сводный отчёт по сотрудникам: счета, платежи, возвраты + активность в чатах |

## Стек
- **ClickHouse** — оконные функции, `WITH RECURSIVE`, `lagInFrame`, `JSON`-функции
- **MySQL** — `JSON_ARRAY_APPEND`, `TIMESTAMPDIFF`, `ROW_NUMBER()`

## Темы
- Иерархии и рекурсивный обход (папки, статьи ДДС, строки ОФР)
- Витрины с полным набором комбинаций (`CROSS JOIN` + `LEFT JOIN` для нулей)
- Заполнение пропусков последним известным значением (`last_value`)
- Сравнение периодов «год к году»
- Дедупликация и исключение двойного счёта через расчётные дельты

# 2. Apache Airflow

Проект на Apache Airflow для оркестрации ETL-пайплайнов и аналитических задач.

**DAGs (`dags/`):**
- `dag_with_clickhouse.py` — интеграция с ClickHouse (загрузка/выгрузка данных).
- `employee_plan_fact.py` — сравнение плановых и фактических показателей сотрудников.
- `sales.py` — обработка и анализ продаж.
- `trend_plan.py` — планирование трендов и прогнозирование.

**Инфраструктура:**
- `Dockerfile`, `docker-compose.yaml` — контейнеризация Airflow и сопутствующих сервисов.
- `nginx.conf`, `nginx/` — reverse proxy для веб-интерфейса Airflow.
- `prometheus.yml` — конфигурация мониторинга.
- `backup.sh` — скрипт резервного копирования.
- `.env.example` — шаблон переменных окружения.
- `requirements.txt` — Python-зависимости.

Проект демонстрирует настройку Airflow «под ключ»: от Docker-образа и nginx до мониторинга и бэкапов, с примерами реальных DAG'ов для аналитики.
